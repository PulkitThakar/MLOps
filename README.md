# MLOps - Weather Prediction using Graph Cast

## Preface

In the recent days, I have been working on a lot of Pipelines in my work. I do find myself really interested in 'how systems work the applications?'. Distributed systems, core development, and topics that take me closer to the computer are my center of interest.

I started off as an application software engineer. And I think DevOps is the next step anyone could take to move closer to core development. Because while you are still seeing things from a very high level, you still are introduced and concerned with how you are going to deploy your software from the hardware standpoint. You start asking questions revolving around the CPU / GPU requirement, memory requirements, requests per unit time and so on.

With the current world progressing more towards AI, CI/CD is required the ML/AI models that you use in any application you build. Hence, calling it MLOps.
